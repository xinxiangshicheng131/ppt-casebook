# 高频坑清单（踩之前先看）

## 一、抓图：可靠度排序

| 渠道 | 可靠度 | 说明 |
|---|---|---|
| **Wikimedia Commons（走代理）** | ★★★★★ | **首选**。国内直连会限流（返回空），**挂代理 `http://127.0.0.1:7890` 立刻恢复** |
| **ArchDaily** | ★★★★ | `images.adsttc.com/media/images/<29位ID>/large_jpg/<文件名>` |
| 政府/高校官网（国内） | ★★★ | 常有图片，但**防盗链**，要带 `-e <页面URL>`，也可能全部失败 |
| worldarchitecture.org | ★★★ | 项目照 1200px，可用 |
| **Bing 图搜** | ☆☆☆☆☆ | **基本不可用**。对具体项目名只返回"题材相近的烂图"：搜"西村大院"给成都夜景，搜"重庆社区体育公园"给洪崖洞，搜"巴黎绿洲操场"给幼儿数学挂图 |
| **Google 图搜** | — | 部分代理节点连不通（返回 000） |
| 澎湃/微信文章 | ★ | 图片 JS 注入；微信反爬页只返回 17KB |

**Commons 搜索词技巧**：
- 搜项目名常常搜不到 → **换作者名、换中文全名、换地名**
  - `Jiakun Architects` 会混进建筑师肖像 → 改用 **`贝森 成都`** 或 **`成都 西村`** 才命中一组（1号楼/2号楼园林/全景图/内庭/立体跑道/足球场）
- 搜不到时先猜"这是不是一个景点/景区名字"

## 二、正则/路径

- **ArchDaily 文件名含下划线**：字符类要写 `[A-Za-z0-9\-_.]`，漏了 `_` 就一张都匹配不到
- **图片 URL 常带查询串**（`?1570209196`），正则不要要求以 `.jpg` 结尾
- **Commons 下载后的实际文件名（01/02/05…）与缩略图索引不是一一对应** → 写 PPT 前必须 `ls` 一遍真实文件名，否则 FileNotFoundError
- 路径拼接别用 `"a/b".join([D, ""])` 这种写法，直接 `os.path.join(D, "a", "b")`

## 三、PIL 自绘图

- **竖坐标越大越靠下**：地下的矩形 `[x0, Y3, x1, Y0]` 会报 `y1 must be >= y0` → 写成 `[x0, Y0, x1, Y3]`
- `draw.text((x), y+30, ...)` 少了逗号 → 报 `got multiple values for argument 'fill'`。**坐标必须是元组 `(x, y)`**
- **图内不要写标题和底注**：塞进 PPT 的宽扁框会被"高度限制"压到只占 60% 宽，图里的字跟着缩水。**先 `im.crop()` 掉自带的标题/底注，再放进框**
- **画之前先把坐标系算清楚**：定义 `X(m)` / `Y(m)` 两个函数（米 → 像素），所有色块用米作单位定位。凭感觉写像素坐标必错位
- 标签位置检查：文字框和色块**上下至少留 0.6 m 的间隙**，否则一定重叠

## 四、PPT 排版

- **python-pptx 不认 Markdown**：文本里写 `**加粗**` 会渲染成字面星号
- **字号 ≥ 20 时的版面**：标题 34–46、副标 20–22、正栏 20–26；每页 ≤ 40 字
- **竖版图（比例 ≈1.3）**在 16:9 里最多占 57% 宽 → 用"左图 6.6 寸 + 右栏 20 pt 文字"
- **横版图（比例 ≥2）**可以占满宽：框 `0.30", 1.40", 12.73", 5.70"`
- 用 `fit()`（等比缩放、居中、不裁切）而不是拉伸
- **导出 PNG 逐页看**：`KWPP.Application`（WPS 演示）的 `Export`，比靠代码猜版式可靠
- **保存前先关 WPS**：`Get-Process wpp | Stop-Process -Force`，否则 `PermissionError: 拒绝访问`

## 五、方案类判断（容易漏的硬约束）

- **屋顶加绿化/上人必须先做结构鉴定**，没资料只能写"需鉴定后确定"
- **文物保护范围内新建** → 引《文物保护法》第十八条；"架空不落地＋轻型结构＋报批"是可批路径（荆州、常州有先例）
- **4 m 高差**：1:20 坡道要 **80 m 长**（放不下），楼梯 27 级约 7.5 m，无障碍另配小电梯
- **屋顶跑道的真门槛是"管理"不是"建设"**：西村一晚涌入 9000 人后被锁 → 方案必须回答"容量上限/入口限流/谁负责"

## 六、交付与承诺

- **自绘图别放进下划线开头的目录**（如 `_dia\`）——文件管理器会排到最后甚至隐藏。用户盯着屏幕找不到图，只会问"图在哪呢，我完全没看见"。建一个正常名字的目录（如 `轴线方案图\`），文件名用中文 `01_xxx.png`
- **出不了效果图就直说**：本环境**没有渲染引擎**，只能出平面/剖面/示意图 ＋ 参考项目实景照。不要用"效果图"这个词含糊过去，也不要先答应再找补
