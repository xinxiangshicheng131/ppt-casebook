# PIL 自绘图技巧（画平面/剖面/示意图）

用 Pillow 画分析图，替代找不到照片的情况，也用于把抽象关系讲清楚。

## 画图前

1. **先定坐标系**：写 `X(m)` / `Y(m)` 两个函数把"米"换算成像素，不要心算坐标。
   ```python
   S = 24  # 1 米 = 24 px
   PX, PY = 300, 150
   def X(m): return PX + m * S
   def Y(m): return PY + m * S
   ```
2. **先列元素清单**再写代码：每个色块、每条线、每个标签的 x/y 范围先算好，再落笔。不要边画边想。
3. 图内**不要写大标题和底注**——这些会跟 PPT 页标题重复；留给 PPT 页面。图内只写元素标签。

## 常见坑（都踩过）

- `d.text((x), y, ...)` 是错的，第一个参数必须是元组 `(x, y)`，否则报 "multiple values for 'fill'"。
- 画地下/下沉时，**y 向下增大**，`rectangle([x0, y0, x1, y1])` 要求 `y1 >= y0`；地下空间要从 `Y0`（地面）画到 `Y3`（更深的 y），不是反着写。
- 标签别压在色块/线上：先画图形，文字放在图外的空白区，或缩进留边。
- 中文字体：`ImageFont.truetype("C:/Windows/Fonts/msyhbd.ttc", size)`（粗体）和 `msyh.ttc`（常规）。
- 输出前用"接触表"预览（把多张图拼成一张格子图 Read 查看），确认没有重叠/越界再交付。

## 尺寸标注

- 尺寸线画在图形**外侧**，标"50 m / 30 m"这类关键数。
- 所有推算尺寸在页脚或图内标"示意，非实测"。

## 成图宽高比

- 16:9 PPT 里，横图（宽高比 ≥ 2.2）可满宽放；**竖图（<1.5）会被压小**，要么配右栏文字，要么裁成更宽的画幅。
- 画完先 crop 掉图内的空白边和重复标题，再放 PPT，否则宽高比不匹配、显示只有 60% 宽。

## 画什么最有效

- **剖面**（把标高、视线、层级画出来）比平面更能讲"关系"。
- **对照表/对照图**（唐长安 vs 场地这类）比单张图更能讲"转译/类比"。
- 一个构件干三件事（抬高树池 = 挡车 + 坐凳 + 蓄水）这类"一图三义"最值钱。
