# 七步模板 · 逐页规格 + 真实范例

> 每本册子都按这七步走。范例取自已完成的绿化册、运动册（东风坊城市设计），照着套。

---

## P1 封面

- 格式：`DEMO｜某某层·L?` ＋ 一句话主题
- 主题句要讲清"这一层解决什么"，一句话，别铺陈。
- 范例：
  - 绿化层 → `DEMO ｜ 绿化系统 · L2 在树之间漫步`
  - 运动系统 → `DEMO ｜ 运动系统 · 架空跑道加绿化`
  - 历史文化 → `DEMO ｜ 历史文化系统 · 记忆长在边界上`

## P2 选案理由

- **只讲"能不能照做"，不讲好看。**
- 先列 2–4 条筛选标准（来自场地硬约束），再写"因此我选了这几个、否掉了哪几个"。
- 否掉的也要写，并给一句理由——能显示你不是随便凑的。
- 范例（绿化册）：标准＝不拆主体 / 不增高（100m 建控带 ≤9m）/ 产权分散。
  否掉卢卡城墙（土坡棱堡≠砖砌城墙）、深水埗（垂直混合≠水平行列式）。

## P3 案例页（每案 2–3 页）

每个案例必须凑齐**四件套**，缺一样不算完成：

1. **一组硬数据**（长度、面积、年份、数量）——标出处
2. **一段原文引用**（甲方/规划文件/设计师原话）——引用比转述有力十倍
3. **实景照片**（不是效果图，不是示意图）
4. **一句"对你的用处"**——说清"抄哪一层、别抄哪一层"

- 版式：图为主体，字只要"一句可直接抄的细节"。
- 每个案例结尾写清**"差别"**，别瞎类比。
- 范例：
  - 龙美术馆（3.3 万㎡）vs 烂尾楼体量小——抄它"未完工混凝土结构→展场"，别抄体量。
  - 清华园老幼一体（同栋楼）vs 你的场地（街区两端）——抄"共享区分时开放"，别抄同楼。

## P4 落到你的场地（自绘）

- 自绘剖面 / 立面 / 平面，把案例的做法"搬"到自己的场地上。
- **必须标"自绘示意，非实测"。**
- 图要带关键尺寸（标高、长度、间距），尺寸要有推导链（见 SKILL.md 的"唯一答案推导法"）。
- 范例：绿化册的 `绿化剖面`（街树 / 3m 墙 / 院内空地 / +4.0 架空 / 视线）＋ `墙的分段`（4 段×6m，每段 4m 洞＋2m 绿）。

## P5 翻译表（全册最有用的一页）

三列表：**你的条件 → 它们的做法 → 你能抄什么**。逐行对照，落到"抄哪个动作"。

- 范例（树冠步道册，六行）：

| 你的条件 | 它们的做法 | 你能抄什么 |
|---|---|---|
| 8 排密植树 | 南非 Boomslang 先测 400 棵树再定柱位 | 先测绘树位，柱躲着树 |
| 贴着树走 | 南非"从树间穿行→缠绕着树→凌驾树冠" | 三段式高差体验 |
| 要一跨过街 | 澳洲钢桁架直接架过去 | 大跨用钢桁架，小段用连续梁 |
| 老树不能伤 | 避不开处在桥面开洞让枝条穿出 | 桥面留洞，别硬挪树 |

## P6 我的建议

- 给 **2–3 种做法 + 一套尺寸 + 推荐组合**，落到具体数字，别停在形容词。
- 范例（3m 墙的三种做法）：① 刷白借影（零造价）② 6m 一开洞 1.5×2.5m（主戏）③ 洞间做 60×60 漏窗（节奏）→ 建议全做，比一面绿墙便宜、好看、也不用管。

## P7 收口

- **每页底部一条"→ 这说明了什么"**，不摆事实就停，指出它指向什么问题、该怎么用。
- 最后一页：把整本的论证链收成一句 + 列出"还待现场确认的事"（尺寸、现状、树种……）。
- 范例（绿化册收口）："在树之间漫步"不是形式问题，是标高问题——三个数字（墙 3.0 / 树冠底 4.0–4.5 / 架空 4.0）咬死了这一层。

## 口径与坑（写册子前先看）

- **一个系统一册，同构**：新册子跟旧册子用同一套七步结构，老师翻起来不跳戏。
- **案例找完要"翻译"，不是"罗列"**：每个案例必须有 P5 那行翻译，否则等于没找。
- **案例要按接口/问题分类**，不要按"场地位置"分（那是地理课，不是设计课）。
- **找不到实景照** → 退一步自绘示意图 + 标"非实测"；**别硬凑题材相近的烂图**。
- **排版/抓图/画图的具体坑** → 读本 skill 的 `references/pitfalls.md`（优先）与 `case-images.md` / `drawing.md` / `ppt.md`。
